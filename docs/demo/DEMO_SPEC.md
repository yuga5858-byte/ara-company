# 制作デモ（工務店・清掃）の仕様

ARVR TECH の営業で見せる、架空の会社の LP（1ページ）と HP（5ページ）。業種を問わず営業するための見本。
作業ブランチの土台：`demo/construction-cleaning`（共通部品が入っている）。各自そこから自分のブランチを切り、Pull Request の向き先も `demo/construction-cleaning` にする。

## 共通ルール

- AGENTS.md の「内容のルール」を必ず守る（架空と明記・口コミや事例は掲載イメージの枠だけ・noindex）
- ページ上部に `DemoBanner`、写真は `DemoPhoto`（差し替え枠）、フォームは `ReserveForm`（送信しない）、LINE ボタンは `LineCta`（LINE に移動しない）を使う
- HP（複数ページ）は `SiteShell`（`app/demo/_components/SiteShell.tsx`）で包む。色と書体は各デモの CSS で変数を定義して `className` に渡す：`--bg --fg --muted --line --surface --accent --accent-fg --body --display`
- メタ情報：`title`・`description`（「架空の〇〇の制作デモ」と書く）・`robots: { index: false, follow: false }`・`openGraph`・`twitter`（既存の `app/demo/gym/page.tsx` と同じ形）
- スマホ優先（幅 375px で崩れない、ボタンは高さ 44px 以上）。既存デモと同じく、追加の UI ライブラリは使わない
- 料金はデモ用の架空の金額で、近くに「※ デモ用の架空の料金です」と書く
- 「最安」「No.1」「地域一番」など根拠のない表現、許可番号・資格番号の創作をしない

## 清掃デモ「ミナモ清掃（MINAMO CLEANING）」— Codex 担当

雰囲気：清潔・明るい・安心。白と淡い水色を基調に、アクセントは落ち着いた青緑。工務店デモ（木の色・落ち着いた暗色）と見分けがつくようにする。

### LP：`app/demo/minamo/`（ハウスクリーニングの LP）

上から順に：
1. ヒーロー：キャッチコピー（例「おうちの『気になる』を、まるごと任せる。」）＋「LINEで見積もり・予約」ボタン（`LineCta`）＋料金を見るボタン
2. こんな方に：共働きで時間がない／年末の大掃除を任せたい／引っ越し前後 など3〜4項目
3. メニューと料金（架空）：エアコン・浴室・キッチン・トイレ・水回り3点セット（カード表示。セットを目立たせる）
4. 作業の流れ：LINEで写真を送る → 見積もり → 日程決定 → 作業 → 仕上がり確認（5ステップ）
5. ビフォー・アフター：`DemoPhoto` の差し替え枠を2組。「※ 掲載イメージです」
6. お客様の声：掲載イメージの枠だけ（既存デモの voices と同じ扱い）
7. よくある質問：5問程度（立ち会い、駐車場、追加料金、キャンセル、支払い方法）
8. 予約フォーム（`ReserveForm`：お名前・電話・希望日・メニュー）＋ `LineCta`
9. スマホの固定ボタン「LINEで見積もり・予約」

### HP：`app/demo/minamo-hp/`（5ページ・`SiteShell` を使う）

| ページ | パス | 中身 |
|---|---|---|
| トップ | `minamo-hp/` | キャッチ、サービスの入口3つ（ハウスクリーニング・定期清掃・オフィス清掃）、選ばれる理由3つ、お知らせ（架空の日付で2〜3件・「デモ」と分かる内容）、予約への導線 |
| サービス・料金 | `minamo-hp/service/` | メニューと料金表（架空）、定期清掃のプラン、オフィス・店舗清掃は「お見積もり」 |
| 作業の流れ | `minamo-hp/flow/` | お問い合わせから作業後までの流れ、当日の準備、よくある質問 |
| 会社案内 | `minamo-hp/company/` | 代表あいさつ（架空の人物・写真は差し替え枠）、会社概要（所在地は「大阪府〇〇市（架空）」）、対応エリア |
| お問い合わせ | `minamo-hp/contact/` | `ReserveForm`（お名前・電話・メール・種類・内容）＋ `LineCta`、営業時間 |

`SiteShell` に渡す nav は上の5ページ、cta は「お問い合わせ」ページ。`current` に今のページのパスを渡す。
