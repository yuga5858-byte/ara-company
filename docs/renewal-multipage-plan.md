# ARA COMPANY 公式サイト マルチページ化 — 構成案（2026-11-14）

依頼：社長「コーポレートサイト全面改修指示書」。この文書は手順2「新しいページ構成の提案」。社長の確認後に実装を始める。

## 1. 今のサイト（調査結果）

- Next.js 16（App Router）・TypeScript・素のCSS（`app/(site)/globals.css`）。`out/` に静的書き出しして Cloudflare Workers で配信。`main` に push すると本番に出る
- 公開ページはトップ `/` の1枚だけ（縦長、ページ内リンク `#about` `#philosophy` `#business` `#services` `#story` `#contact`）
- ほかに制作デモ `/demo/` 以下（gym・salon・kisu・kisu-hp・minamo・minamo-hp）。tech.ara-company.jp の制作事例からリンクされている → **URLを変えない**
- お問い合わせはメールだけ。フォーム部品 `ContactForm` はあるが、送信先 `site.contactEndpoint` が未設定のため表示していない
- 料金は `app/services.ts`（Webサイト制作 59,800円〜／開業記念 39,800円〜、運用・AIは「お見積り」）
- プライバシーポリシーのページはない
- 内容は、ファッション（ORMOSCIA・立ち上げ準備中）・AI/テクノロジー（ARVR TECH）・スポーツ・コミュニティの事業構想と、企業理念・OUR STORY・代表メッセージ

## 3. URL変更とリンク切れ対策

- 今あるページの URL は `/` と `/demo/*` だけで、どちらも残すので 301 転送は不要
- 外部から `/#services` などのページ内リンクで来た人のために、トップで旧アンカーを新ページへ案内する小さな処理を入れる（`#services`→`/services/`、`#about`・`#philosophy`・`#story`・`#business`→`/about/`、`#contact`→`/contact/`）
- `sitemap.xml` を新しい10ページに更新（デモは載せない）。各ページに固有の title・description・canonical を付ける
- 全ページの内部リンクを自動で巡回して、リンク切れがないか確認する

## 4. デザイン

和モダン × ミニマル × テクノロジー。白・黒・グレーを基調にし、今の朱の印（落款）をアクセントとして控えめに残す。墨・水の背景アニメーション（`Water`・`InkField`）はトップのファーストビューだけに弱めて残すか、外す。ボタン・リンクは2種類（塗り・線）に統一。
