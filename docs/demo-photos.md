# 制作デモの写真について

制作デモ（`/demo/gym/`・`/demo/salon/`）の写真は、利用条件を確認した写真が用意できるまで「PHOTO」の差し替え枠を表示しています。

## 差し替え方法

1. 写真を `public/demo/gym/` または `public/demo/salon/` に置く（例：`public/demo/gym/hero.jpg`）。
2. 各ページの `photos` の該当項目に `src` と `credit` を入れる。

```ts
hero: { src: "/demo/gym/hero.jpg", alt: "…", brief: "…", credit: "Unsplash / 撮影者名 / Unsplash License" },
```

3. 横幅は 2000px 程度まで、JPEG または WebP（1枚 300KB 前後が目安）に縮小してから置く。

## 写真を選ぶときの確認事項

- 商用利用できるライセンスか（Unsplash License・Pexels License は商用利用可・クレジット表記は任意。ただし規約は変わることがあるため、ダウンロード時点の規約を確認する）
- 写っている人物・ロゴ・建物について、モデルリリースや商標の問題がないか（実在のジムやサロンの店内・ロゴが写っているものは避ける）
- 実在の店舗の写真だと誤解される使い方をしない（デモである表示は消さない）
- 出典・撮影者・ライセンスを `credit` に記録しておく
- 実際のお客様のサイトでは、お客様ご自身の写真か、撮影を依頼した写真を使う
